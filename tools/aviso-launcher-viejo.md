## ¿Tu launcher se queda en «Actualizando el launcher… Casi listo» o en «No se pudo descargar la actualización»?

Tu launcher es de una versión antigua que no puede actualizarse sola. Esperar o reintentar no lo arregla.

1. Cierra el launcher (si no se cierra: Administrador de tareas → «SC Launcher» → Finalizar tarea).
2. **[Descarga el launcher {VERSION} aquí](https://descargas.servidorcobblemon.es/SC-Launcher-setup-{VERSION}.exe)** e instálalo encima del que tienes.

Solo hay que hacerlo una vez y no pierdes nada (cuentas, ajustes y mundos se quedan): a partir de ahí se actualiza solo.
