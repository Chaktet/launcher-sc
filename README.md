# SC Launcher

Launcher oficial de **Servidor Cobblemon** (servidorcobblemon.es).

- Perfiles PRO y LITE (gama baja)
- Login premium (Microsoft) y no premium
- Instala automáticamente Java 21, Fabric, mods y resourcepacks
- Entrada directa al servidor con un clic

**Descarga:** https://descargas.servidorcobblemon.es/SC-Launcher-setup-1.0.0.exe

Basado en [Helios Launcher](https://github.com/dscalzi/HeliosLauncher).
